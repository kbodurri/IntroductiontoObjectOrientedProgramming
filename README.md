# Introduction to Object Oriented Programming

Assingments for the course Introduction to Object Oriented Programming (CE325). The course goes through 4 projects in Java and C++.

A summary of the course:

    1. Classes and Objects
    2. Inheritance and hierachy of classes.
    3. Method overloading
    4. Operator Overloading
    5. Polymorphism
    6. Interfaces and abstract classes
    7. Exceptions 
    8. File I/O
    9. Java Generics → Java Collections Framework
    10. C++ Templates → C++, STL
    11. Network I/O
    
For more information please visit -> [Wiki Course](https://courses.e-ce.uth.gr/CE325/doku.php?id=start)
